> **一句话总纲**：AI 只负责画面，中文和版式由 HTML 排版完成，两者最后合成。
> 下面这张海报就是这条流水线的产物——底图来自 AI，上面的中文字一个都不是。

![海报成品](/images/ai-poster/poster.jpg)
*图 1｜成品：「AI 分不清星期几？」——底图由 AI 生成，所有中文由 HTML/CSS 排版*

## 一、为什么中文不能交给图像模型

扩散模型对"字形"没有概念，它画的是"像字的纹理"：笔画会缺、横竖会连、小字必糊。越是多笔画的汉字，翻车越明显。

所以第一条铁律是：**所有中文一律后期排版**，要 AI 画的只有画面本身。

![AI 底图](/images/ai-poster/background.jpg)
*图 2｜AI 只交付这一层：六个一模一样的白色方块，暗场和留白都留给排版*

## 二、流程（八步）

| 步骤 | 做什么 | 关键点 |
|---|---|---|
| 01 收信息 | 标题 / 副标 / 时间地点 / 调性 / 素材 / 尺寸 | 一次问完，不猜 |
| 02 灰模 | 灰块定信息层级 | 层级没定，不生成画面 |
| 03 选来源 | Krea / Seedream / ComfyUI / 纯排版 | 按场景选，不按喜好 |
| 04 提示词 | 固定三件套 | 禁字、留白、印刷质量 |
| 05 取图 | 下载底图 | 部分图片域名国内直连会超时，走 CDN |
| 06 排版 | HTML / CSS | 字体 ≤2 种，颜色 1 主 1 辅 |
| 07 三验 | 眯眼 / 灰度 / 扫码 | 不过不交付 |
| 08 交付 | PNG + PDF + HTML 源文件 | 改字只动 HTML |

### 01｜先收信息

六个问题一次问完：说什么、副标题、时间地点主办、调性、必用素材、尺寸用途。信息没到齐就开工，十次有九次要返工。

### 02｜灰模

只用灰块排位置：主标题占 1/3，主视觉的位置先定死，信息区最小、但要能扫。**先看层级，再谈好看。**

### 03｜画面来源怎么选

| 场景 | 路线 | 理由 |
|---|---|---|
| 电影感 / 写实 / 氛围 | Krea 3（先 1K 试稿） | 质感最好，能改图保构图 |
| 中文标题要长在画面里 | Seedream 4.5（豆包 / 即梦） | 少有的能把中文排得像样的 |
| 印刷质感 / Mondo / 手绘 | 本地 ComfyUI + SDXL | 免费、可控 |
| 公告 / 讲座 / 通知 | 不出图，纯排版 | 出图反而降低可读性 |

### 04｜提示词三件套

任何底图提示词都要带上这三行：

```
no text, no letters, no logos, no watermark
large clean empty area in the upper third for a title
print quality
```

### 05｜取图

部分 AI 生图服务的图片域名国内直连会超时。可以用公开 CDN 中转：

```
https://wsrv.nl/?url=<图片地址>
```

下载落盘之后再排版，别在浏览器里对着预览调。

### 06｜HTML 排版

- A4 = 210×297mm，300dpi → **2480×3508px**，四周 3mm 出血
- 屏幕预览用 1240×1754（150dpi）就够
- 字体只用系统字体（思源宋体 / 黑体、微软雅黑），**一族里用不同字重分层级**
- 颜色：1 个主色 + 1 个强调色，其余黑白灰
- 导出：浏览器 2x 截图出 PNG；PDF 用无损嵌入（PIL 直接存会按 JPEG 重编码，暗部出色带）

![Mondo 风格案例](/images/ai-poster/mondo-poster.jpg)
*图 3｜同一套方法换一种画风：Mondo / 丝网印刷质感的校园海报——字依然是排版层*

### 07｜三验

1. **眯眼测试**：眯到看不清字，仍然一眼能看出主次。
2. **灰度测试**：转成黑白，层级不塌（印刷黑白稿最容易翻车）。
3. **扫码测试**：二维码按 3cm 宽输出，手机实扫能出。

## 三、常见翻车（做了就是错）

- 把中文写进图像提示词
- 先出图，再想版式
- 一次丢五个微调版本让人选
- 满版装饰，没有留白
- 字体超过两种、颜色超过两种

## 四、工具边界

| 工具 | 强 | 弱 |
|---|---|---|
| Krea 3 | 改图保构图、电影感、系列一致 | 不会写字、2K 上限、无版式 |
| Seedream 4.5 | 中文密集排版、多图锁主体 | 审美偏电商、模板感 |
| 本地 ComfyUI（SDXL） | 免费、风格可控（Mondo / 丝网） | 慢、需要调参 |
| 纯 HTML/CSS | 精确、可改、可印刷 | 做不了画面 |

## 小结

海报这件事，真正决定质量的是**分工**：AI 负责它擅长的画面质感，排版负责它永远做不好的中文字。

把这条分工记住，剩下的就是耐心：先灰模、再出图、最后三验。
