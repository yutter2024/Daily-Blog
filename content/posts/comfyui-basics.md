## Z-Image 模型的普通工作流

![Z-Image 模型的普通工作流：模型加载、提示词、空 Latent、采样与 VAE 解码](/images/comfyui/image1.webp)

*图 1｜Z-Image 的默认文生图工作流，一条线从左串到右。*

工作流里各个节点的作用：

| 节点 | 作用 |
|---|---|
| CLIP 文本编码 | 也叫提示词。一般有两个，一个是正向提示词：想要生成的内容；一个是负向提示词：不想要生成的内容 |
| K 采样器 | 控制整个工作流 |
| 步数 | 降噪的次数，一般设置在 20~30 之间 |
| CFG | 控制最终生成的图像和提示词的匹配程度，一般设置 5~8 之间 |
| 采样器 | 一般选择 dpmpp-2m 或者 dpmpp-2m-sde |
| 调度器 | 一般选择 simple |
| 降噪 | 控制画面的噪点，一般选择 1 |
| 空 Latent | 宽度，高度：控制图片生成比例 |
| 批次 | 选择一次性可以生成多少张图片 |
| U-Net 加载器 | 用于选择模型 |
| VAE 解码 | 转换接头，把 Latent 图像变成像素空间 |
| 其他 | 剩下的就不用管了，默认就行 |

## CLIP 文本编码器工作原理

- 上半部分：提示词通过 Transformer 转变成特征向量，也叫文本编码
- 下半部分：图片（训练集）通过 Vit 或者 ResNet 转换成特征向量

![CLIP 文本编码器的上下两条路径](/images/comfyui/image4.webp)

*图 4｜完整的采样链路：CLIP 编码 → U-Net 加噪降噪 → 重复 N 次 → VAE 解码。*

### K 采样器工作原理

输入提示词，然后由 CLIP 转化成特征向量，特征向量随后被发送到 U-Net 中。高斯噪声（Gaussian Noise），就和种子差不多，不同的种子生出来的图像也不同，然后高斯噪声会输入到 Latent 中，Latent 就相当于一层画布，高斯噪声会填满整个 Latent。随后整个被高斯噪声填满的 Latent 会输入到 U-Net 中和特征向量结合，U-Net 就会预测下一步的降噪对象以及减少噪声。随后被降噪的图像会经过固定的循环次数就会被发往 VAE，VAE 就会把 Latent 图像变成我们可见的图片。

![K 采样器在整条链路里的位置](/images/comfyui/image5.webp)

*图 5｜一次降噪循环的四个阶段：编码、加噪、循环采样、解码出图。*

### 图生图工作原理

输入图像，然后图像 VAE 可以把图形变成潜空间图像，然后发送到 K 采样器，随后会添加噪声，发送到 Latent 图像中，但这个 Latent 图像是有内容的，不是空 Latent。随后这个 Latent 图像和特征向量，会被发送到 U-Net 中。然后经过采样降噪循环之后，就会被发往 VAE 解码器中，随后生成图像。
