> 如果你现在连「一个单词该怎么记」都不确定，这份教程从最基础开始。你不需要先懂记忆科学，也不需要先买 Anki；先用纸和手机，跟着一个词做完全过程。第一阶段的目标不是一天背 100 个词，而是把每天 3—5 个词真正推进到「能在句子和对话中使用」。

## 你读完今天就要完成什么

| 结果 | 具体标准 |
|---|---|
| 知道一个词是什么 | 不只知道中文，还知道它在原句里的意思、词性和使用场景 |
| 听得出一个词 | 先听声音，再看文字；能在完整句里认出它 |
| 想得起一个词 | 看到中文场景或挖空句，不看答案能说出英语 |
| 用得出一个词 | 能写自己的句子，换对象/原因后仍能使用 |
| 说得出一个词 | 能在一个问题和回答中自然用一次 |

### 先记住这条最重要的规则

> **「背过」不等于「学会」。** 看到 issue 知道是「问题」，只是认识；听到 The main issue is... 能补出 issue，才有听力记忆；看到「现场主要问题是安全」能说 The main issue on site is safety，才开始有表达能力；别人问 What is the main issue? 你能回答，才进入真实使用。

### 今天的第一课：只学一个词块

不要一开始拿一张 100 个词的词表。今天选一个你真正需要的表达：**fall behind schedule**（进度落后）。你会用它学习完整流程，之后所有新词都照这个流程做。

| 时间 | 你现在做什么 | 不要做什么 |
|---|---|---|
| 第 1—3 分钟 | 听原句，猜场景 | 不要马上抄中文 |
| 第 4—7 分钟 | 看文字，确认意思和发音 | 不要查十个词义 |
| 第 8—12 分钟 | 记一个搭配和一个原句 | 不要只记 fall = 落下 |
| 第 13—16 分钟 | 遮住答案回忆 | 不要只重新看一遍 |
| 第 17—20 分钟 | 换成自己的句子并说出来 | 不要只在心里默读 |

本教程后面会把每一步展开。现在先理解：学习的单位不是「一个拼写」，而是「一个声音 + 一个意思 + 一个搭配 + 一个句子 + 一次主动使用」。

## 第一章：从 0 开始，你先要知道「单词」由什么组成

### 1.1 一个英语词不是一张中文标签

中文母语者常见的第一种背法是：把英文写在左边，把中文写在右边。例如 issue = 问题，delay = 延迟。这种方法可以帮助你第一次认出词，但它没有告诉你这个词怎么发音、和什么词一起出现、在句子中怎么变化、什么场合能用。

| 你要记住的层 | 它回答的问题 | 以 delay 为例 |
|---|---|---|
| 声音 | 别人说出来时我能认出吗？ | 听到 de-LAY / delayed 能反应 |
| 形式 | 拼写和词形是什么？ | delay、delayed、delays |
| 核心意思 | 当前句子里是什么意思？ | 延期/使某事晚一点 |
| 搭配 | 它通常和谁一起出现？ | delay the project；delivery delay |
| 句型 | 它在句中怎么放？ | be delayed because of... |
| 个人联系 | 和我的生活有什么关系？ | Our project was delayed... |
| 对话反应 | 别人问我时能不能用？ | Why was it delayed? |

### 1.2 你要区分四种「会」

| 层级 | 你能做到什么 | 适合的卡片/练习 |
|---|---|---|
| 认识 | 看到英文知道大概意思 | 英文→中文识别卡 |
| 听懂 | 只听声音也能认出词块 | 音频卡：先听后看 |
| 回忆 | 从中文场景生成英语 | 中文场景→英文表达卡 |
| 迁移 | 换场景、回答问题时仍能用 | 替换句、角色对话、录音 |

从 0 开始时，不要要求每个词都立刻达到第四层。阅读中遇到的普通词，做到认识和听懂就可以；与你的专业、考试或口语目标有关的词，再推进到回忆和迁移。

### 1.3 你需要准备什么

- 一个纸质笔记本或手机表格：先不用任何复杂软件。
- 一个可以播放例句音频的可靠词典：先听当前句子，再看解释；不要只看中文。
- 一段你大部分能听懂的英语材料：视频、短文、课堂材料都可以。材料太难时，词汇会变成无底洞。
- 每天 20—40 分钟的固定时间：先从可持续开始，而不是一上来制定两小时计划。
- 一个录音工具：手机录音即可，用来检查自己能否从提示说出完整句子。

### 1.4 从今天开始，不再做三件事

- 不把遇到的每个生词都做成主动卡。先筛选，减少无效复习。
- 不把一个词的所有中文释义都塞进一张卡。先学当前场景里的核心义。
- 不把「重新看了五遍」当作复习完成。复习必须有遮挡、回忆和检查。

## 第二章：第一天到底怎么记一个词——完整示范

### 示范目标：fall behind schedule

场景：项目进度落后。你可能在建筑、学校小组作业或日常安排中使用它。今天不背 schedule 的所有意思，只学一个可以立即使用的词块：fall behind schedule。

| 项目 | 内容 |
|---|---|
| 原始句 | We are falling behind schedule because the materials arrived late. |
| 中文场景 | 因为材料晚到，我们的进度落后了。 |
| 今天的目标 | 听懂、补出、改写、在回答中说出 |
| 今天不做 | fall 的十个意思；schedule 的全部词义；长篇词源 |

### 第 0 步：先建立「我为什么学它」

在纸上写：我想用这个词表达什么？不要写「我想记住英文」。写具体一点：我想告诉别人项目为什么没有按计划完成。具体用途会给记忆一个钩子。

现在填写（不要先看答案）：

- 中文场景：我想用英语表达：________________________
- 我可能在哪个场合使用：学校 / 工地 / 日常 / 其他：________
- 我希望别人问我什么问题：________________________

### 第 1 步：先听，不看文字

播放原句 3 遍。第一遍只回答「发生了什么」；第二遍注意你听到的声音；第三遍试着判断目标词出现在哪里。听不出来很正常，因为你还没有把声音和文字连接起来。此时不要立即责怪自己「记忆差」。

| 第几遍 | 你的任务 | 合格标准 |
|---|---|---|
| 第 1 遍 | 只听大意 | 知道是在说进度、材料或时间 |
| 第 2 遍 | 抓目标声音 | 大概听到 behind / schedule 的一部分 |
| 第 3 遍 | 暂停前后各听一次 | 知道目标词块在句中的位置 |

### 第 2 步：看英文，把声音和文字接上

现在看原句：`We are falling behind schedule because the materials arrived late.`

第一次学习时，允许看文字；但看文字的目的，是把声音、拼写和句子连起来。不要一边看文字一边假装自己听懂了。下一轮要把文字遮住重新听。

### 第 3 步：只确认当前核心意思

当前句子里，fall behind schedule 的意思是「进度落后/没有按计划进行」。不要现在同时学习 fall 的全部意思，也不要把 schedule 的所有释义都抄下来。词典里的其他意思以后遇到再学。

现在不要堆十个同义词和罕见例句。当前要保留的只有：**fall behind schedule = 进度落后**；原句；一个个人场景。

### 第 4 步：拆开，但不要拆散

拆开是为了理解结构，最后仍要把它作为一个可调用的词块。fall behind 是「落后于」，schedule 是「进度/时间安排」。英语里常说 fall behind schedule，而不是临时把中文逐字翻译。

| 部分 | 作用 | 你要会做的事 |
|---|---|---|
| fall | 动词核心 | 知道这里表示进入「落后」状态 |
| behind | 介词/位置关系 | 理解为落后于某个标准 |
| schedule | 名词对象 | 这里是计划/进度安排 |
| falling | 进行时形式 | 知道 We are falling 表示正在落后 |

### 第 5 步：记录声音，不靠中文谐音

跟着原音说 3 遍：fall behind schedule。先追求节奏和整体，不要把每个音节读得像中文拼音。可以在词块上标出重音和停顿：fall behind **SCHEDULE**。再听原句，模仿它在句子中的速度。

如果你知道音标，可以查；如果不知道，先不用把音标当成门槛。对初学者来说，可靠音频 + 分段跟读 + 录音对比，比自己根据拼写猜发音更安全。

### 第 6 步：只找两个搭配

| 搭配 | 意思 | 例句 |
|---|---|---|
| fall behind schedule | 进度落后 | We are falling behind schedule. |
| be on schedule | 按计划进行 | The project is still on schedule. |
| （下一步再学）keep to the schedule | 遵守进度安排 | We need to keep to the schedule. |

第一次只选 2—3 个搭配。搭配不是为了让卡片变长，而是为了让你知道这个词在真实英语里和谁一起出现。

## 第三章：从「看懂」到「想起」——主动回忆是核心

### 第 7 步：做第一张识别卡

识别卡的目的，是让你看到英文或听到声音时知道意思。它不是最终目标，但它是起点。

| 卡片正面 | 卡片背面 |
|---|---|
| fall behind schedule | 进度落后；原句 We are falling behind schedule because the materials arrived late. |
| 播放原句音频，不显示文字 | 原句文字 + 中文场景 + 两个搭配 |

### 第 8 步：做填空卡——把答案藏起来

| 正面提示 | 你要说的答案 |
|---|---|
| We are falling ___ schedule. | behind |
| We are ___ behind schedule. | falling |
| 项目进度落后怎么说？ | The project is falling behind schedule. |

第一次做时可以给首字母提示，例如 f___ b______ s________。第二次减少提示。第三次只保留中文场景。提示的作用是帮助你成功回忆，不是永久依赖。

### 第 9 步：从中文场景生成自己的句子

现在不要再照抄原句。把原句中的对象换掉。你可以先从非常简单的事实开始：

| 中文提示 | 英文答案 |
|---|---|
| 我们的课程进度落后了。 | Our course is falling behind schedule. |
| 我的小组作业进度落后了。 | Our group project is falling behind schedule. |
| 我们因为材料晚到而进度落后。 | We are falling behind schedule because the materials arrived late. |
| 项目没有落后，仍按计划进行。 | The project is still on schedule. |

### 第 10 步：把词放进一个问题和回答

词汇真正进入口语，需要从「背答案」变成「对问题做反应」。先读问题，再遮住答案：

| 问题 | 回答 |
|---|---|
| Are you on schedule? | No. We are falling behind schedule because the materials arrived late. |
| Why are you falling behind schedule? | Because the delivery was delayed. |
| What can you do? | We can adjust the schedule and check the materials when they arrive. |

### 第 11 步：第一次口头验收

关闭词典和笔记，打开手机录音。给自己 20 秒准备，然后回答：**What is one thing that is behind schedule this week?**

你不需要说得漂亮，但必须尝试使用 fall behind schedule 或 be on schedule。录音结束后再看原句，检查词块是否完整。

**第一天的验收表**

- [ ] 我听过原句至少 3 遍。
- [ ] 我看着英文能说出中文场景。
- [ ] 我遮住目标词能补出句子。
- [ ] 我能把对象换成自己的事情。
- [ ] 我录音说过一次，而不是只在心里想。
- [ ] 我已经安排第 2 天和第 4 天复习。

## 第四章：完整案例——issue 从 0 到能对话

### 4.1 第一次遇到 issue，先不要背全部意思

原句：**The main issue on site is safety.** 场景：有人在讨论施工现场最主要的问题。当前只学 issue 在这里的核心意思「问题/主要问题」。

| 处理顺序 | 你要写下什么 | 为什么 |
|---|---|---|
| 原句 | The main issue on site is safety. | 保留真实语境 |
| 中文场景 | 现场主要问题是安全。 | 不要只写一个词的翻译 |
| 词性 | issue 是名词；the main 修饰它 | 知道它在句子里的位置 |
| 声音 | 听整句，不单独慢读中文式发音 | 建立听力形式 |
| 核心词块 | the main issue is... | 开口时直接调用 |
| 个人句 | The main issue in our group project is time. | 和自己建立联系 |
| 问题 | What is the main issue on site today? | 准备真实对话 |

### 4.2 issue 的四张卡

| 卡片类型 | 正面 | 背面/答案 |
|---|---|---|
| 识别卡 | the main issue is... | 主要问题是……；原句 |
| 听力卡 | 只播放 The main issue is safety. | 文字和意思 |
| 填空卡 | The main ___ is safety. | issue |
| 表达卡 | 「现场主要问题是安全」 | The main issue on site is safety. |

### 4.3 五次回忆，不要连续看五遍

- 回忆 1：看 issue，说「问题，名词」。
- 回忆 2：听 The main issue is safety，暂停后补出 issue。
- 回忆 3：看到中文「主要问题是时间」，说 The main issue is time。
- 回忆 4：看到「设备有问题」，说 There is an issue with the equipment。
- 回忆 5：回答 What is the main issue in your study?，至少说两句。

### 4.4 从一个词块扩展到词块家族

| 表达 | 意思 | 例句 |
|---|---|---|
| the main issue is... | 主要问题是…… | The main issue is the schedule. |
| an issue with... | ……有问题 | There is an issue with the equipment. |
| raise an issue | 提出问题 | We need to raise an issue with the supplier. |
| deal with an issue | 处理问题 | The team is dealing with a safety issue. |

不要第一天把四个表达都要求达到主动使用。第一天先把 the main issue is... 练熟；第二次遇到 issue 时，再加入 an issue with...；需要工作交流时，再加入 raise/deal with。词族和搭配是逐步扩展，不是一次塞满。

## 第五章：拼写、发音、词形怎么记——不要混成一团

### 5.1 先判断你是哪一种忘记

| 你遇到的情况 | 忘的是哪一层 | 对应练习 |
|---|---|---|
| 看到中文想不起英文 | 表达回忆 | 中文场景→英文卡；先给首字母提示 |
| 看到英文认识，听到不认识 | 声音 | 音频卡；先听短词块再听整句 |
| 听到能懂，写不出拼写 | 形式/拼写 | 听后写关键词，再与原文核对 |
| 词会说，但句子搭配不自然 | 用法 | 保留原句和两个搭配，做替换句 |
| 原句会说，换场景不会 | 迁移 | 换对象、时间、原因，再做问答 |

### 5.2 声音怎么从 0 开始练

从零开始不要求你先掌握所有音标。你只要完成一个声音循环：**听原句 → 看英文 → 标出词块 → 跟读 → 暂停复述 → 录音对比**。每次只挑一个问题，例如重音、词尾、停顿或连读，不要一次纠正全部。

| 轮次 | 动作 | 以 issue 为例 |
|---|---|---|
| 1 | 只听原句 | 判断 issue 在句子中出现的位置 |
| 2 | 看文字再听 | 把听到的声音和 issue 拼写连上 |
| 3 | 跟读短词块 | the main issue；重复 3 遍 |
| 4 | 跟读整句 | The main issue on site is safety. |
| 5 | 暂停后自己说 | 不看文字复述整句 |
| 6 | 放进个人句 | The main issue in my class is time. |

### 5.3 词形变化要怎么学

第一次遇到一个词，只先学当前句中的形式。例如 inspect the site。第二次遇到 inspection，再比较它是名词；第三次遇到 inspector，再加入表示人的形式。不要因为知道 inspect 就假设 inspection 和 inspector 自动会用。

| 词形 | 词性/功能 | 先记哪个搭配 |
|---|---|---|
| inspect | 动词，检查 | inspect the site / inspect the materials |
| inspection | 名词，检查/检查活动 | a safety inspection |
| inspector | 名词，检查人员 | a site inspector |
| delayed | 过去式/过去分词 | The delivery was delayed. |
| delay | 动词或名词 | delay the project / a delivery delay |

词根、词缀和词族可以帮助你理解和分类，但它们不是记忆的终点。每一个词形都要回到真实搭配和句子里。

## 第六章：从 0 开始制作词卡——纸笔版和手机版

### 6.1 纸笔词卡：先照这个模板写一张

| 栏位 | 你要填写的内容 | 示范 |
|---|---|---|
| 1. 目标词块 | 写可使用的片段，不只写词根 | fall behind schedule |
| 2. 原句 | 从材料里抄完整句 | We are falling behind schedule because the materials arrived late. |
| 3. 场景 | 用中文说明当时发生什么 | 材料晚到，项目进度落后 |
| 4. 核心义 | 只写当前最重要的意思 | 进度落后 |
| 5. 词性/结构 | 写它在句中的位置 | fall + behind + schedule |
| 6. 搭配 | 写 2 个自然组合 | be on schedule；keep to the schedule |
| 7. 音频 | 注明要听哪一句 | 原句第 10 秒—第 13 秒 |
| 8. 挖空 | 遮住目标词块 | We are falling ___ schedule. |
| 9. 我的句子 | 写自己的真实句子 | Our group project is falling behind schedule. |
| 10. 复习日期 | 写下次什么时候回忆 | 今天、明天、第 4 天、第 8 天 |

### 6.2 一张卡的正面和背面应该怎样分

| 卡片方向 | 正面只放 | 背面放 |
|---|---|---|
| 识别 | 英文词块或音频 | 中文场景、核心义、原句 |
| 填空 | 带空的句子 | 目标词块 |
| 表达 | 中文场景/问题 | 完整英文回答 |
| 听力 | 音频，不显示文字 | 原文、意思、词块边界 |

如果你刚开始，先只做识别卡和填空卡；第三天以后再加表达卡。不要一开始制作复杂卡片，否则制作卡片会替代真正的回忆练习。

### 6.3 手机备忘录的最简单格式

```text
目标词块：__________________
原句：______________________
中文场景：__________________
两个搭配：__________________
挖空句：____________________
我的句子：__________________
第 2 / 4 / 8 / 15 天：□ □ □ □
```

### 6.4 Anki 什么时候再用

Anki 只是帮助你安排回忆，不会替你决定什么词值得学，也不会自动让你会说。刚开始先用纸或备忘录跑通一周；你能够稳定完成「先回忆、再看答案、再造句」后，再把高价值卡迁移到 Anki。每天先做旧卡，再加新卡；复习积压时暂停新增。

## 第七章：复习到底怎么做——不是重新看，而是先想

### 7.1 每次复习的固定动作

- 第一步：遮住答案，只看中文场景、问题、音频或挖空句。
- 第二步：给自己 3—8 秒尝试回忆；不要一秒想不起就马上翻答案。
- 第三步：说出来或写出答案；「在脑中觉得认识」不算完成。
- 第四步：打开答案，比较词块、词形、搭配和发音。
- 第五步：如果错了，立刻再说一次；如果对了，做一个小替换。

### 7.2 从第一天到第 30 天的复习安排

| 时间点 | 先回忆什么 | 成功后的动作 | 失败后的动作 |
|---|---|---|---|
| 学完后 | 原句挖空和中文场景 | 说一个个人句 | 重新听原句，缩短目标 |
| 当天晚上 | 听音频补词块 | 不看文字再说一次 | 标记困难，不连续抄写 |
| 第 2 天 | 中文→英文、英文→意思 | 替换一个对象 | 保留原句，明天再测 |
| 第 4 天 | 混合顺序抽查 | 加入一个为什么问题 | 回到语境听两遍 |
| 第 8 天 | 用 3 个词块说 30 秒 | 录音保存 | 减少新卡，保留困难卡 |
| 第 15 天 | 放进一次对话 | 升级为主动词 | 降回填空卡 |
| 第 30 天 | 不按原顺序综合回忆 | 放进专业主题口述 | 重新安排短间隔 |

### 7.3 用 0、1、2 分记录，不要凭感觉

| 分数 | 表现 | 下一步 |
|---|---|---|
| 2 分 | 不看答案能说出正确词块和完整句 | 照原计划拉长间隔 |
| 1 分 | 看一个提示或想很久才说出 | 保留卡片，缩短下一次间隔 |
| 0 分 | 完全想不起，或搭配错误到无法使用 | 回到原句/音频，改短卡，暂停同类新词 |

### 7.4 什么时候算「记住」

一个词块至少完成下面四项，才可以暂时从「重点复习」转为「长期复习」：

1. 隔一天听到能认出；
2. 看到中文场景能说出；
3. 换一个对象或原因能改句；
4. 在一次口述或对话里主动使用。

只完成「看到英文知道中文」，不要急着把它标记为掌握。

## 第八章：为什么单词一定要进入句子

### 8.1 孤立词不能直接变成口语

说话时你不是从词典中挑一个中文意思，再把它翻译成英文。你需要迅速调用「词块 + 句型」。因此每个主动词至少保留一个完整原句，再做一到两个替换。

| 原句 | 替换位置 | 变成你的句子 |
|---|---|---|
| The project was delayed because of heavy rain. | 对象 | The delivery was delayed because of heavy rain. |
| 同上 | 原因 | The project was delayed because of traffic. |
| 同上 | 时间 | The project was delayed last week. |
| 同上 | 改成问题 | Why was the project delayed? |
| The main issue is the schedule. | 地点/问题 | The main issue on site is safety. |
| We need to inspect the site. | 对象 | We need to inspect the materials. |

### 8.2 七轮学习一句话

- 第 1 轮只听：谁在说什么？
- 第 2 轮看英文：目标词块在哪里？
- 第 3 轮查关键点：最多查一两个影响理解的词。
- 第 4 轮跟读：模仿节奏和停顿三遍。
- 第 5 轮暂停：不看文字，从记忆说出整句。
- 第 6 轮改写：换一个人、时间、对象、原因或地点。
- 第 7 轮使用：回答一个问题，至少说一次。

### 8.3 句子验收练习

**遮住右边，先自己说：**

| 中文 | 你的答案 |
|---|---|
| 项目因为交通而延期。 | ______________________ |
| 现场主要问题是安全。 | ______________________ |
| 我们需要检查材料。 | ______________________ |
| 问题：Why was the delivery delayed? | ______________________ |

**参考答案：** The project was delayed because of traffic. / The main issue on site is safety. / We need to inspect the materials. / It was delayed because of traffic.

先尝试，再对照；不要在看答案前给自己判分。

## 第九章：怎么把刚记的词放进真实对话

### 9.1 先学对话动作，不要等到词汇量很大

| 动作 | 可直接使用的表达 | 你可以放入的词块 |
|---|---|---|
| 开始 | Can I ask you something about...? | the schedule / the delivery |
| 回答 | I think... / In my experience... | The main issue is... |
| 解释原因 | The main reason is... / Because... | be delayed because of... |
| 追问 | What about you? / Why do you think so? | Why was it delayed? |
| 没听清 | Could you say that again more slowly? | 让对话继续 |
| 不会某词 | I do not know the exact word, but... | 用描述代替停住 |
| 修正 | Let me say that again. | 重新说正确搭配 |
| 结束 | Thanks, that was helpful. | 回顾今天用过的词 |

### 9.2 15 分钟词汇对话

| 时间 | 怎么做 | 限制 |
|---|---|---|
| 0—3 分钟 | 用熟悉词介绍今天的学习/专业 | 不查词，只启动 |
| 3—8 分钟 | 围绕一个主题问 5 个问题 | 强制使用本周 2—3 个词块 |
| 8—11 分钟 | 对方追问、要求解释或澄清 | 不要每句话都被打断纠错 |
| 11—13 分钟 | 记录 3 个最重要的错误和 3 个自然表达 | 不纠正所有小错误 |
| 13—15 分钟 | 重新回答其中 2 个问题 | 必须把修正后的词说出来 |

**可复制给 AI 的提示词：**

```text
请和我进行关于施工现场进度的英语对话。我是中文母语者，约 B1 水平。
本轮只练 the main issue is、be delayed because of、adjust the schedule、
inspect the materials、fall behind schedule。请先问我 5 个问题，不要每句
打断；结束后只指出 3 个最影响理解的错误和 3 个更自然的词块，再让我
重新回答其中 2 题。
```

## 第十章：从 YouTube、X 和其他材料中挑词

### 10.1 YouTube 一条视频只挖 5 个词块

| 时间 | 动作 | 词汇输出 |
|---|---|---|
| 0—2 分钟 | 看标题和画面，预测主题 | 写 3 个可能出现的词 |
| 2—6 分钟 | 不看字幕完整听 | 只记录听到的词，不暂停查 |
| 6—10 分钟 | 打开英文字幕核对 | 选 5 个高价值、可理解、能使用的词块 |
| 10—15 分钟 | 精听 30 秒—2 分钟并跟读 | 每个目标词听原句至少 3 遍 |
| 15—18 分钟 | 关字幕复述 | 强制使用其中 2 个词块 |
| 18—20 分钟 | 写个人句并安排复习 | 留下不超过 5 张高质量卡 |

BBC/VOA 可用于较清晰输入；Rachel's English 可用于重音、弱读和连读；Easy English 可用于真实回答和停顿；其他教师频道可用于句型示范。这里的关键不是看了哪个频道，而是每条内容都经过「听懂—选词—做卡—造句—开口」的转化。

### 10.2 X 短视频或帖子：先恢复语境，再学一句

| 步骤 | 动作 | 你留下的东西 |
|---|---|---|
| 1 | 读原帖、引用帖、画面文字 | 知道这句话在回应什么 |
| 2 | 播放两遍，只抓一个名词、一个动词、一个重复短语 | 3 个候选词 |
| 3 | 用字幕/评论确认，不盲信自动字幕 | 修正后的句子 |
| 4 | 选一句你真的会用的表达 | 例如 I can't believe this happened again. |
| 5 | 换成自己的事实并说出来 | I can't believe I forgot the deadline again. |
| 6 | 写一句英文反应后关闭 X | 一次输出，不继续被动刷 |

X 和社区内容可以提供真实表达、学习者的失败经验和方法争论，但它们不是分级教材。若一条内容需要查十几个背景词，就先放到识别篮，不要硬做主动卡。

### 10.3 Reddit/论坛内容怎么变成学习材料

- 先找一个你真正关心的问题，例如「怎么练口语」「为什么背了会忘」。
- 只提取一个表达和一个观点，不把整条讨论当课文。
- 把表达放进自己的句子，再用一句英文写出你是否同意。
- 把个人经验标记为「社区经验」，不要因为很多人赞同就当成科学定论。

## 第十一章：从 0 开始的 14 天单词训练计划

前 14 天不追求大词量，只训练正确动作。每天 20—40 分钟。每周新增约 25—40 个主动词块已经足够；如果复习积压，立刻减半。

| 天数 | 当天重点 | 必须完成 |
|---|---|---|
| 第 1 天 | 学会一张词卡 | 用 fall behind schedule 做完整十步流程，录 20 秒 |
| 第 2 天 | 第一次间隔回忆 | 不看答案补 3 个挖空，造 1 句 |
| 第 3 天 | 学习声音 | 听 3 个原句，跟读，记录一个发音问题 |
| 第 4 天 | 搭配和替换 | 把一个句子换对象、原因各一次 |
| 第 5 天 | 学习 issue | 完成识别卡、填空卡、表达卡 |
| 第 6 天 | 问答 | 回答 What is the main issue? 并追问一次 |
| 第 7 天 | 周测 | 不看原文说 30 秒，复盘 3 个词块 |
| 第 8 天 | 新材料挖词 | 从一条短视频选不超过 5 个词块 |
| 第 9 天 | 听力卡 | 把 2 个词做成音频→文字卡 |
| 第 10 天 | 中文→英文 | 用 5 个中文场景生成英语 |
| 第 11 天 | 词形 | 比较 inspect、inspection、inspector |
| 第 12 天 | 对话 | 进行 10—15 分钟 AI 或真人对话 |
| 第 13 天 | 修复弱点 | 清理 0 分卡，暂停新增 |
| 第 14 天 | 综合验收 | 用 10 个词块做 2 分钟专业主题口述 |

### 每天 20 分钟的最低版本

| 分钟 | 动作 | 底线成果 |
|---|---|---|
| 0—6 | 回忆旧卡，先不看答案 | 至少尝试 10 张 |
| 6—11 | 学习 2—3 个新词块和原句 | 每个有场景 |
| 11—16 | 做填空和中文→英文回忆 | 每词主动提取 2 次 |
| 16—20 | 说个人句并录音 | 至少说出 2 个词块 |

### 每天 40 分钟的标准版本

| 分钟 | 动作 | 底线成果 |
|---|---|---|
| 0—8 | 旧卡复习 | 10—15 张，记录 0/1/2 分 |
| 8—16 | 从视频/帖子选 5 个词块 | 不做整张词表 |
| 16—24 | 查核心义、词性、搭配、音频 | 每词 2 搭配 |
| 24—32 | 填空、中文提示、听力回忆 | 每词 2 次主动提取 |
| 32—40 | 造句、录音、安排复习 | 5 句 + 30 秒口述 |

## 第十二章：你记不住时，不要只说「我记性差」

| 症状 | 实际断在哪一步 | 修复动作 |
|---|---|---|
| 看中文想不起英文 | 没有做生产性回忆 | 加中文场景→英文卡，先给首字母提示 |
| 看英文认识，听不到 | 声音和文字没有连接 | 增加原句音频卡，短词块循环听 |
| 只记得一个中文意思 | 没有词性、搭配和句型 | 回到原句，补 2 个搭配和一个挖空 |
| 原句会说，换场景不会 | 没有做替换 | 固定换对象、原因、时间三个位置 |
| 当天记住，第二天忘 | 没有间隔后的主动提取 | 固定第 2 天复习；当天少重复 |
| 卡片越来越多 | 新增量超过恢复能力 | 暂停新卡 3 天，先清理旧卡 |
| 对话不敢用 | 没有低压力试用和补救句 | 先录音，再 AI，再真人 |
| 跟读很像但不会自由说 | 只模仿，没有脱稿回忆和改写 | 每次跟读后必须做个人句和问答 |

### 12.1 失败卡片怎么重做

- 先删掉无关信息：只留当前核心义、原句、音频和一个挖空。
- 把长句缩短，但不要失去场景。例如先用 The delivery was delayed，再逐步加 because of traffic。
- 把主动表达改成识别卡，重新建立理解；不是每张卡都必须立刻用于口语。
- 换成你真正经历过的场景。越接近你的生活，越容易在对话中调用。
- 连续失败三次时暂停这张卡，不要在同一天机械重复二十遍。隔天换材料再遇到它。

### 12.2 每周只看四个数据

| 数据 | 记录方法 | 如何判断 |
|---|---|---|
| 主动词块数 | 本周能从中文提示说出的词块 | 比收藏总数更重要 |
| 0 分卡数量 | 完全想不起或无法使用的卡 | 多就减少新卡 |
| 口语使用数 | 在录音/对话中真正说出的词块 | 低就增加迁移训练 |
| 重复错误 | 同一个搭配错误出现几次 | 高就做专门句型卡 |

## 第十四章：把「从 0 开始」变成长期学习系统

### 14.1 每个词都走同一条路

| 阶段 | 你做什么 | 通过标准 |
|---|---|---|
| 输入 | 从较容易的材料遇到词块 | 知道它来自什么场景 |
| 理解 | 确认核心义、词性和原句 | 能说出当前句子意思 |
| 声音 | 听音频、跟读、暂停复述 | 听到时能认出 |
| 回忆 | 填空、中文场景→英文 | 不看答案能说出 |
| 改写 | 换对象、原因、时间、地点 | 不依赖原句顺序 |
| 对话 | 回答、追问、澄清、修正 | 真实交流中用一次 |
| 间隔 | 第 2/4/8/15/30 天回忆 | 不靠当天熟悉感 |

### 14.2 30 天后的目标不要写成「背了多少词」

写成可以观察的结果：我能听懂多少短视频主题；我能从中文场景说出多少词块；我能用多少词块讲自己的专业；我能否回答一个问题并追问；同一个错误是否减少。词汇量是结果，不是每天唯一应该追的数字。

### 14.3 证据强度怎么理解

| 方法 | 证据/来源类型 | 在本教程中的位置 |
|---|---|---|
| 主动回忆、间隔复习 | 学习科学研究和二语学习综述，支持较强 | 作为每个词的核心复习动作 |
| 语境、词块、可理解输入 | 研究与教师/机构实践共同支持 | 用原句和可理解材料选词 |
| 跟读、声音模仿 | 部分研究和教师实践支持 | 作为发音/听觉训练，不当完整课程 |
| YouTube/X/Reddit 方法 | 教师示范和社区经验，证据较不一致 | 转成具体任务，不能当万能规律 |
| AI 角色对话 | 对话式语言学习研究与实践正在发展 | 低压力重复，仍要真人反馈 |

你真正要坚持的不是某个 App，也不是某个频道，而是这个闭环：**从容易理解的材料选一个高价值词块 → 听懂并看懂 → 遮住答案回忆 → 改成自己的句子 → 在对话中用 → 间隔后再次回忆。**

### 14.4 最终检查清单

- [ ] 我没有把所有生词都做成主动卡。
- [ ] 每个主动词都有原句、音频/声音、核心义和至少一个搭配。
- [ ] 我做过英文→意思，也做过中文场景→英文。
- [ ] 我把至少一半主动词改成了自己的句子。
- [ ] 我在录音或对话中用过本周词块。
- [ ] 我按照第 2、4、8、15、30 天回忆，而不是只在当天重复。
- [ ] 复习积压时，我会减少新词，不会继续堆。

这份教程把研究、教师频道和学习社区的做法转成了从 0 开始的操作步骤。来源类型不同，结论强度也不同：主动回忆和间隔复习有较强研究支持；词块、句子挖掘和平台工作流是研究与教学实践的综合；X/Reddit 中的个人经验只能作为可试用的策略。

| 来源类别 | 本教程采用的内容 |
|---|---|
| 学习科学/二语研究 | 主动回忆、间隔学习、重复接触、口语反馈、对话式语言学习 |
| Paul Nation Four Strands | 输入、输出、语言聚焦、流利度；用于平衡整套学习系统 |
| YouTube 教师实践 | BBC/VOA：清晰输入；Rachel's English：声音与重音；Easy English：真实回答；Leonardo English：泛听与精听 |
| Refold 与 sentence mining 实践 | 从自己理解大部分的内容中选含少量新点的句子，不把每个生词都做卡 |
| X/Reddit/论坛经验 | 真实表达、学习者的失败模式和方法争论；作为社区经验，不当作科学定论 |

### 主要核验来源名称

- Dunlosky 等：Improving Students' Learning With Effective Learning Techniques。
- 二语间隔学习与重复/偶然词汇学习的元分析。
- Paul Nation：The Four Strands。
- 口头反馈、shadowing、script-assisted shadowing 相关研究。
- Dialogue-based CALL speaking meta-analysis。
- Refold：Comprehensible Input 与 sentence mining 实践。
- BBC Learning English、VOA Learning English、Rachel's English、Easy English、Leonardo English 的教学实践。
- 关于 X 辅助专业英语学习以及可理解输入争议的研究/社区讨论。
