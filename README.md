<summary><b>维护者笔记：写文章、本地预览、发布检查</b></summary>

### 写新文章

在 `content/posts/` 新建 `.md`（front matter 参照已有文章），或：

```bash
hugo new content posts/my-post.md
```

### 本地预览

```bash
hugo server --port 1313
# http://127.0.0.1:1313/
```

### 发布前检查

- front matter 完整：`draft: false`、`slug`、`description`、`tags`、`posttype`
- 配图放 `static/images/`，正文引用 `/images/xxx.png`
- `hugo --minify` 无报错后再推送

### 发新作品（一条命令）

```bash
# 海报：生成 1600×900 封面 + ≤3840 原图，并写入 data/works.yaml
python scripts/work_assets.py poster --src <4K图> --slug my-poster \
  --title "作品名" --date 2026.11 --note "一句话" --write

# 视频：切 14–20s 精彩片段 + hover 小样 + 封面，并写入 data/works.yaml
python scripts/work_assets.py video --src <final.mp4> --start 0 --dur 15 \
  --title "作品名" --series 科普 --date 2026.11 --note "一句话" --write

# 体检 + 构建
python scripts/work_assets.py check --build
```

### 目录结构

| 路径 | 用途 |
|---|---|
| `content/posts/` | 全部文章（Markdown） |
| `content/categories/` | 分类页介绍文案 |
| `data/works.yaml` | 作品墙数据源（视频/海报） |
| `static/images/` | 文章配图与作品素材 |
| `static/images/works/` | 作品封面、精彩片段、原图 |
| `assets/css/extended/` | 自定义样式（排版标准） |
| `themes/PaperMod/` | 主题源码（已入库，含本地定制，勿整目录覆盖） |
| `.github/workflows/` | 部署与索引维护工作流 |
| `scripts/` | README 索引、作品资产流水线 |
